# Evangelium

Evangelium è un RPG testuale in cui vesti i panni di un discepolo, e l'ordine religioso che scegli plasma le tue opzioni di dialogo. Incontrerai diversi NPC da guidare attraverso complessi alberi di conversazione, usando le Scritture e le parole dei Santi per risolvere i loro conflitti interiori. Ottimizza le tue risposte per guadagnare risorse, sbloccare nuovi testi e superare i livelli di Fede, Speranza e Carità.

## Come eseguire il progetto

### Prerequisiti

* Java 25 (LTS)
* Gradle (9.6.1)

### Istruzioni

```bash
git clone https://github.com/AldoTavoletti/Evangelium.git
cd Evangelium
```

### Build del progetto

```bash
./gradlew build
```

### Esecuzione

```bash
./gradlew run
```

## Uso di strumenti di AI

Per la realizzazione di Evangelium è stato utilizzato Gemini come assistente tecnico e strumento di confronto. L'intelligenza artificiale è stata impiegata per esaminare possibili strategie implementative, valutare alternative di design e supportare la risoluzione di problemi tecnici, operando sempre sotto un'attenta supervisione e revisione personale.

### Attività svolte con il supporto di Gemini

* **Valutazione architetturale:** supporto nell'analisi di pattern e best practice (come l'adozione di un Composition Root) per strutturare correttamente l'applicazione.
* **Debugging e risoluzione errori:** confronto per individuare l'origine di anomalie in fase di compilazione ed esplorare possibili soluzioni.
* **Documentazione e Clean Code:** supporto nella revisione del codice per migliorarne la leggibilità, la manutenibilità e la coerenza dei commenti tecnici.
* **Principi SOLID:** analisi congiunta per identificare potenziali criticità nel codice e valutare opzioni di refactoring.
* **Generazione dei contenuti:** stesura creativa dei dialoghi teologici e strutturazione dei file JSON che compongono la campagna di gioco.
* **Stile dell'interfaccia:** supporto per la stesura dei fogli di stile (CSS) e per l'ottimizzazione dell'interfaccia utente.
* **Redazione della documentazione:** stesura delle bozze testuali iniziali per questo file README e per le pagine della Wiki, accuratamente revisionate, riadattate e in molte parti completamente sostituite dalla mia analisi personale.

### Intervento personale

L'intelligenza artificiale ha ricoperto esclusivamente il ruolo di supporto consultivo:

* Ciascuna opzione o soluzione proposta è stata analizzata criticamente, testata e riadattata in base alle specifiche esigenze del progetto.
* L'ideazione del gioco, la definizione dei requisiti e la stesura dell'intera architettura sono frutto esclusivo del lavoro personale.
* Ogni decisione progettuale finale, così come l'implementazione del codice, rispecchia scelte autonome e consapevoli, maturate valutando i pro e i contro emersi durante il confronto con l'AI.

In sintesi, l'intelligenza artificiale ha operato come un'estensione della mia capacità analitica, non come un sostituto. È stata uno strumento al servizio della logica, escludendo ogni forma di automatismo per garantire che ogni riga di codice riflettesse una mia precisa e consapevole scelta ingegneristica.

Per ulteriori informazioni e per il dettaglio sull'utilizzo dell'AI, consultare la Wiki del repository.
